# Claude Code理解度診断Webアプリ 設計書

## 背景・目的

チーム内でClaude Codeの育成・研修を行う際、メンバーの理解度を客観的に把握する手段がない。
理解度レベル別の問題集を用意し、回答結果から個人の理解度を判定できるWebアプリを作る。

対象は個人・チームレベルでの利用であり、より大きな組織運用や管理機能（アカウント管理、
チーム全体の集計ダッシュボードなど）はスコープ外とする。

## 想定利用シーン

チームリーダーやメンター、あるいはメンバー本人が、Claude Codeの理解度を診断し、
弱点領域を把握して次の学習ステップを決めるために使う。診断結果はレポート（PDF）として
出力し、1対1の育成面談や自己申告の材料として使う。

## スコープ外

- チーム全体の結果を自動集計するダッシュボード
- サーバーサイドでのユーザー管理・認証
- 複数人の結果を横断比較する機能
- 組織・管理者向けの権限管理機能

## ホスティング

GitHub Pages（静的サイトホスティング）。サーバーサイド処理を持たないため、
ビルドツール不要のVanilla JS（HTML/CSS/JS）で実装し、リポジトリをそのまま
GitHub Pagesに公開する。

## アーキテクチャ

```
/
├── index.html          # トップページ（説明・診断開始）
├── quiz.html            # 診断ページ
├── result.html          # 結果・レポートページ
├── css/
│   └── style.css        # 通常表示 + @media print でPDF印刷対応
├── js/
│   ├── quiz-engine.js    # 出題・採点ロジック
│   ├── level-judge.js    # 理解度判定ロジック
│   ├── report.js         # 結果表示・改善提案生成
│   └── storage.js        # localStorage 読み書き
└── data/
    └── questions/
        ├── basic-operations.json      # 基本操作・CLI使用法
        ├── feature-usage.json         # 機能活用（ツール・MCP・フック）
        ├── prompt-design.json         # プロンプト設計・協働作法
        └── security-permissions.json  # 安全性・権限管理
```

データはサーバーに送信せず、診断結果はブラウザの`localStorage`にのみ保存する。
個人利用が前提のため、チーム集計機能は持たない。結果の共有はレポート（PDF）の
エクスポートを通じて手動で行う。

## 問題データ

### 対象領域（4領域）

1. 基本操作・CLI使用法
2. 機能活用（ツール・MCP・フック）
3. プロンプト設計・協働作法
4. 安全性・権限管理

### 理解度レベル（4段階）

初級 → 中級 → 上級 → エキスパート

### データ構造

各領域のJSONファイルに、レベルタグ付きの問題プールを格納する。

```json
{
  "domain": "basic-operations",
  "domainLabel": "基本操作・CLI使用法",
  "questions": [
    {
      "id": "basic-001",
      "level": "beginner",
      "question": "...",
      "choices": ["...", "...", "...", "..."],
      "correctIndex": 0,
      "explanation": "..."
    }
  ]
}
```

出題形式は単一選択式（4択）のみ。自動採点が容易でシンプルな実装で済む。

### メンテナンス

開発者がリポジトリ内のJSONファイルを直接編集して問題を追加・修正する。
GitのPRレビューを通じて品質を担保する。アプリ内に問題管理UIは作らない。

## 診断フロー

1. トップページで診断を開始
2. 各領域につき、4レベル（初級・中級・上級・エキスパート）から一定数ずつ出題し、
   1領域あたり合計10問（計40問前後）とする。各レベルの問題プールからランダム抽出し、
   1問ずつ回答して進む（進捗表示あり）
3. 全問回答後、結果ページへ遷移し自動採点・判定
4. 結果はlocalStorageに保存され、再訪時に直近結果を復元可能

## 判定ロジック

### 領域別レベル判定

各領域の正答率（10問中の正答数）を閾値で判定する。

| 正答率 | レベル |
|---|---|
| 90%以上 | エキスパート |
| 70%以上90%未満 | 上級 |
| 50%以上70%未満 | 中級 |
| 50%未満 | 初級 |

### 総合レベル判定

4領域のうち最も低いレベルを総合レベルとする（木桶原理）。
一部領域が高くても、苦手領域があれば総合評価に反映させることで、
弱点を見逃さない設計とする。

## レポート

結果ページに以下を表示し、ブラウザの印刷機能（`window.print()` + `@media print`スタイル）
でPDF化できるようにする。

- 領域別レベルと正答率（4領域）
- 総合レベルと正答率
- 弱点領域（最も低いレベルの領域）に対する改善提案テキスト
  - レベル×領域の組み合わせごとに静的な提案文をあらかじめ用意し、該当するものを表示

設問ごとの正誤詳細（どの問題を間違えたか）はレポートに含めない。
スコアと改善提案のみのシンプルなレポートとする。

## エラーハンドリング

- 問題データの読み込み失敗時はエラーメッセージを表示し、再読み込みを促す
- localStorageが利用不可な環境（プライベートブラウジング等）では、結果保存をスキップし
  その場でのレポート表示のみ行う旨を案内する

## テスト方針

- `quiz-engine.js`の出題ロジック（各領域から重複なく10問選ぶ）の単体テスト
- `level-judge.js`の閾値判定・総合レベル集約ロジックの単体テスト
- ブラウザでの手動確認: 診断フローの一連の流れ、印刷レイアウトの確認
